# VerVox Cards

A Snakow storefront with 4 card listings and 20 cards in total stock.

## Stock model

- 4 card listings
- 5 cards per listing
- 20 cards total
- Single cards: $0.50
- Card packs: $1.50

## Run it

Open `index.html` in a browser, or publish the repository with GitHub Pages.

The static demo prepares an order email in the visitor's email app. It does not charge customers or store live inventory on a server.
